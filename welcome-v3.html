Welcome to Aurora OS

V3 Desktop Edition — a polished, open-source Linux desktop project for Surface Pro 3.

Explore

Use the Applications menu or the Aurora top bar to open your desktop apps.

Personalize

Open Control Center to change appearance, display, keyboard, touch, power, sound, and network settings.

Install software

Aurora Store opens GNOME Software. Install apps from configured trusted sources.

Surface testing

Test Wi-Fi, touchscreen, pen, rotation, sleep, battery, audio and keyboard before installing to the internal drive.

Hardware compatibility varies. This live image is a project build and is not yet verified on real Surface Pro 3 hardware.
